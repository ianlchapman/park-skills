# park-attractions

Per-park attraction data: rides and other attractions with height rules,
type, and thrill level. Height rules come from the park's own published
attraction pages and **can change** — always check `lastChecked` and tell the
user to confirm with the sign at the ride entrance.

## Data location

One JSON file per park in `data/`, named by park slug (same slugs as
`park-info`): `data/<slug>.json` (e.g. `data/europa-park.json`).

Not every park has attraction data yet. If there is no file for a park, say
attraction data isn't available for it rather than guessing.

Generated by an external pipeline from hand-researched data. Don't hand-edit
these files.

## File shape

```json
{
  "parkId": 51,
  "parkSlug": "europa-park",
  "parkName": "Europa-Park",
  "attractions": [
    {
      "id": "europa-park-arthur",
      "name": "ARTHUR",
      "area": "Minimoys Kingdom",
      "type": "Dark ride",
      "thrill": 2,
      "minHeightCm": 120,
      "accompaniedMinHeightCm": 100,
      "singleRider": true,
      "openingYear": 2014,
      "manufacturer": "Mack Rides",
      "seasons": ["summer", "halloween", "hallowinter", "winter"],
      "description": "...",
      "sourceUrl": "https://...",
      "lastChecked": "2026-10-09",
      "confidence": "high"
    }
  ]
}
```

- `type`: `Coaster`, `Water`, `Dark ride`, `Flat ride`, `Family`, or `Show`.
- `thrill`: 0 = no thrill, 1 = gentle, 2 = moderate, 3 = intense. This is an
  editorial judgement, not a park-published rating.
- `minHeightCm`: minimum height to ride **alone** (0 = no minimum).
- `accompaniedMinHeightCm`: lower minimum when riding **with an adult**
  (0 = no lower limit). Absent means there is no accompanied exception.
- `maxHeightCm`: maximum height, when the ride has one.
- `notes`: age rules and quirks the height fields can't express (e.g. "ages 6-12
  must be accompanied"). Always relay these. `confidence: "low"` rows say why here.
- `seasons`: when the ride normally operates (`summer`, `halloween`,
  `hallowinter`, `winter`); absent if unknown. Rides also close for
  maintenance, so check the park's live status for today.

## Answering height questions

A rider of height H can ride a ride if `H >= minHeightCm`, or if
`accompaniedMinHeightCm` is present, `H >= accompaniedMinHeightCm` and they
are with an adult. Also check `maxHeightCm` where present. Mention when a
ride is only possible with an adult.
